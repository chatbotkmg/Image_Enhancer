
CatID-Enhancer: Noise-aware Super-Resolution Model (v1)

A resource-efficient pipeline solution for high-quality cat ID image enhancement

📌 Project Overview

Traditional approaches such as increasing the depth of a GAN (e.g., Pix2Pix) often lead to significantly increased computational requirements, especially when targeting higher-resolution image generation.

During this project, the training was performed under strict resource constraints (Kaggle environment with frequent Out of Memory errors). Adding more layers or using larger-resolution inputs regularly caused:

Memory failure (OutOfMemoryError)

Vanishing or exploding gradients

Excessively long training time

Unstable convergence when attempting larger models

➡️ Therefore, instead of further deepening the GAN, a separate noise-aware image enhancement model (super-resolution network) was introduced as a post-processing pipeline stage.

This approach proved:

A lightweight, modular enhancement model can effectively improve image quality without adding major complexity to the GAN itself.
It allows the generator to focus on structure, while the enhancer handles clarity and noise suppression.

🎯 Objective

Enhance low-resolution, artifact-prone outputs generated by earlier Cat-ID GAN models, producing significantly cleaner, higher-quality portrait images suitable for ID-style use.

This pipeline strategy:
✔ Avoids deep model expansion
✔ Is more GPU-efficient
✔ Achieves targeted image quality improvement
✔ Enables progressive refinement (can be stacked or iterated if needed)

🧠 Training Strategy

Epoch 1–100 → L1 loss only

Epoch 100–300 → CombinedLoss (L1 + detail reconstruction)

No GAN used in this stage — purely enhancement-focused model

Adam optimizer

Custom visualization tool (visualize_batch) used for monitoring image recovery progress

Although trained up to only epoch 300, quality improvement was already visually significant and deemed satisfactory for v1.
